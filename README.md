# Relay-Skill

Задания другим ИИ-агентам через файлы проекта, без серверов: очередь
`.relay/`, исполнитель будится фразой «посмотри файл go.md», работает в своей
git-ветке и worktree, возвращает короткий отчёт. Правила общения хранятся в
скилле, в репозиторий проекта не попадают.

## Установка

```bash
git clone https://github.com/RungeKut/Relay-Skill.git "<папка скиллов агента>/relay"
```

Рядом нужен скилл skill-skill (общие правила, проверки, хук). Настройка
клона — skill-skill, `knowledge/40_СРЕДА/40-01`; зависимости набора —
`knowledge/40_СРЕДА/40-01` здесь.
