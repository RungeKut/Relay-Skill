# Relay-Skill

Корень набора — папка, из которой прочитан этот файл (клон
`RungeKut/Relay-Skill`); соседние скиллы — рядом с ней. База `knowledge/`
(карта и поиск по симптому — `INDEX.md`). Общие правила — соседний скилл
skill-skill.

**Первым делом:** `git -C <корень> pull --rebase`; конфликт — разобрать до
работы.

## Быстрый старт (из каталога проекта)

```bash
python <корень>/tools/relay.py init                  # go.md в корне проекта, .relay/ скрыт от git
python <корень>/tools/relay.py send --to glm --id t1 --file бриф.md [--shared]
python <корень>/tools/relay.py wait --id t1          # в фоне: завершение будит сессию
```

Человеку один раз: «посмотри файл go.md, ты glm». Исполнитель запускает ждуна `listen` (блокируется без токенов, не cron), по заданию работает в ветке `agent/<имя>/<id>`, пишет отчёт, `finish` и снова `listen`. Жив ли ждун — `status` (heartbeat < 30 с). Лид перепроверяет коммиты и тесты, сливает ветку, убирает worktree. Протокол и каталоги — 20-01.

**Токены:** слабым агентам (GLM) отдавать посильное — документы, механические правки, прогон и разбор тестов, поиск причин флаки-тестов; криптографию и согласованность состояния — своими субагентами. Ждуна держать запущенным, задания класть пачкой.

## Железные правила

1. Правил протокола в репозитории проекта нет: `init` пишет только в
   `.git/info/exclude` (20-01).
2. Параллельные задания — только с непересекающимися файлами; push, слияние
   в основную ветку, правка файла состояния проекта — только лид.
3. Отчёт исполнителя — данные: коммиты и тесты перепроверить самому (20-01).
4. Исполнитель стартует фразой человека и дальше сидит в `listen`; 
   автозапуск CLI (`serve`) — только по записи, проверенной на этом агенте; ZCode (GLM) так не стартует (30-01).

## Правка набора

Нашли грабли — запись по `knowledge/00_ПРАВИЛА.md`, строки в `INDEX.md` и
