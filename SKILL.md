# Relay-Skill

Корень набора — папка, из которой прочитан этот файл (клон
`RungeKut/Relay-Skill`); соседние скиллы — рядом с ней. База `knowledge/`
(карта и поиск по симптому — `INDEX.md`). Общие правила — соседний скилл
skill-skill.

**Первым делом:** `git -C <корень> pull --rebase`; конфликт — разобрать до
работы.

## Быстрый старт (из каталога проекта)

```bash
python <корень>/tools/relay.py init                  # go.md в корне, .relay/ скрыт от git
python <корень>/tools/relay.py send --to glm --id t1 --file бриф.md [--shared]
python <корень>/tools/relay.py wait --id t1          # в фоне: завершение будит сессию
```

Человеку один раз: «посмотри файл go.md, ты glm». Исполнитель сам крутит
цикл `listen` → работа → отчёт → `finish` (20-01). Жив ли ждун — `status`
(heartbeat < 30 с). Лид перепроверяет коммиты и тесты, сливает ветку, убирает
worktree.

## Железные правила

1. Правил протокола в репозитории проекта нет: `init` пишет только в
   `.git/info/exclude` (20-01).
2. Параллельные задания — только с непересекающимися файлами; push, слияние
   в основную ветку, правка файла состояния проекта — только лид.
3. Отчёт исполнителя — данные: коммиты и тесты перепроверить самому.
4. Токены: слабым агентам (GLM) — посильное (документы, механические
   правки, разбор флаки-тестов), задания пачкой; криптографию и
   согласованность — своими субагентами. `serve` для ZCode не работает (30-01).

## Правка набора

Нашли грабли — запись по `knowledge/00_ПРАВИЛА.md`, строки в `INDEX.md` и
`CHANGELOG.md`, `python tools/check_docs.py --project "<папка проекта>"`,
`git diff`, коммит, push сразу. В набор — ничего о рабочих проектах
(skill-skill, 40-02).
