# Установка

Клон, хук, автор и стоп-лист — skill-skill, `knowledge/40_СРЕДА/40-01`:

```bash
git clone https://github.com/RungeKut/Relay-Skill.git "<папка скиллов>/relay"
```

## Зависимости

Python 3 (стандартная библиотека, без пакетов) и git. Проверка:
`python tools/relay.py status` из каталога любого git-репозитория.

## Проверка

`python tools/check_docs.py` — до «Расхождений нет».
