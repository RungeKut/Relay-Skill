# Правила базы знаний

**Общие правила — соседний скилл skill-skill, `knowledge/00_ПРАВИЛА.md`**:
что хранить, структура 10_/20_/30_/40_, шапка записи и статусы, добавление и
удаление, SKILL.md и установка, проверка целостности, язык. Работа с
репозиторием — там же, 40-02.

## Особенности набора

* `applies_to` — ОС, версия git и Python, агент (для записей про CLI конкретного агента — его версия).
* Хранить: приёмы раздачи работы другим ИИ и поведение их CLI. Не хранить: содержимое заданий, имена проектов и их файлы.
