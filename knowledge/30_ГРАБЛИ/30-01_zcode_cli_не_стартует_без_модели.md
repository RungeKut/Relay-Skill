# ZCode CLI не стартует автоматически

## Что происходит

Точка входа CLI — `<каталог ZCode>/resources/glm/zcode.cjs`; запускать её
надо самим приложением как Node: `ELECTRON_RUN_AS_NODE=1 ZCode.exe zcode.cjs
-p "<промпт>" --cwd <каталог> --mode <режим>` (`--help` показывает опции).
Дальше по цепочке:

1. `Cannot find ... Built-in Provider Config` — конфиг провайдера CLI ищет в
   `<каталог точки входа>/provider/zcode-builtin.json`, а в установке он
   лежит в `resources/config/provider/`. Обход без правки установки:
   прокладка `zcode.cjs` со строкой `require("<путь>/resources/glm/zcode.cjs")`
   и копия конфига в `provider/` рядом с ней.
2. После прокладки: `Error: Select a model before sending a message` —
   модель по умолчанию в CLI не задана; ни `-c`, ни `--resume` её не
   подставляют, флага выбора модели в `--help` нет.
3. Режим `tui` (где можно выбрать `/model`): `Cannot find package '@zcode/tui'` —
   пакет в установку не входит.

## Как правильно

Автозапуск ZCode через `relay.py serve` не использовать; запускать GLM
вручную фразой «посмотри файл go.md» (20-01). Вернуться к проверке при
новой версии ZCode (проверить `-p` и наличие `@zcode/tui`).

## Как неправильно

Опрашивать каталог сторожем, который запускает `-p` вхолостую: каждое
задание кончится `status: fail` с этой ошибкой.

## Чем подтверждено

Запуски из терминала Windows, вывод ошибок выше; исходник `zcode.cjs`
(поиск места выбора модели) — модель берётся из конфигурации сессии, откуда
именно, не выяснено.
